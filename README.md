This project uses **machine learning** to predict the **success rate of movies** based on features such as genre, budget, runtime, language, and more.

It was developed as a practical application of ML workflows — from **data preprocessing** to **model training**, **evaluation**, and **prediction**.

---

## 🎯 Project Goal

To build a predictive model that classifies whether a movie is likely to succeed (hit) or not (flop), based on historical and structured data.

---

## 🧠 Machine Learning Workflow

- Data Cleaning & Feature Engineering  
- Exploratory Data Analysis (EDA)  
- Encoding Categorical Variables  
- Model Building (Logistic Regression, Random Forest)  
- Model Evaluation using Accuracy, Precision, Recall, and F1 Score  
- Predictive Deployment Logic

---
